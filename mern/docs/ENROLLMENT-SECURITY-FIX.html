Enrollment Without Login — Security Fix Guide

Project: TechNexa (Legacy live app + MERN app)  |  Date: 16 November 2026  |  Status: Fixed & Deployed

1. Problem

On the live site (http://54.161.79.42/), a visitor who is not logged in could click "Enroll Now" on any course card. This opened the full enrollment form (name, email, phone, CNIC, photo, payment receipt, etc.) and the form submitted successfully to /api/enroll — creating an enrollment record in the database without any authentication.

Security impact: Unauthenticated users could submit enrollment requests with arbitrary data and file uploads. This is a High-severity issue.

2. Root Cause

LayerIssue
Backend (server.js)/api/enroll endpoint had no authentication check. Anyone could POST enrollment data + files.
Frontend (js/script.js)The "Enroll Now" click handler opened the enrollment modal (#courseModal) with the full form regardless of login state. No check for window.__cnxUser.

3. Fix Applied (Legacy Live App)

3.1 Backend — server.js (line ~646)

Added an authentication guard at the start of the /api/enroll handler. If the user is not logged in (req.user is falsy), return 401 Unauthorized immediately — before any file processing or database writes.

app.post("/api/enroll", (req, res, next) => {
  upload.any()(req, res, (err) => { ... });
}, async (req, res) => {
  // NEW: Require authentication
  if (!req.user) return res.status(401).json({
    ok: false,
    msg: "Please register or log in first to enroll."
  });
  // ... rest of enrollment logic
});

3.2 Frontend — js/script.js (openModal function)

Modified openModal() to check window.__cnxUser. If the user is not logged in:

  • Hide the enrollment form (form.style.display = "none")
  • Show a "Please register or log in first" card with Log in and Register buttons (in the modal's success panel area)
  • The enrollment form is never shown to unauthenticated users
function openModal() {
  // ... reset fields ...
  var me = window.__cnxUser;
  if (!me) {
    // Not logged in — show login/register gate instead of the form
    form.style.display = "none";
    if (successEl) {
      successEl.innerHTML =
        '
 Please register or log in first
' +
        '
You need to register or log in before enrolling...
' +
        '
' +
        'Log in' +
        'Register' +
        '
';
      successEl.hidden = false;
    }
  } else {
    prefillFromSession();
    form.style.display = "";
  }
  modal.classList.add("open");
  // ...
}

3.3 Cache Busting — *.html

Updated the cache-busting query string from ?v=20261025 to ?v=20261116f in all HTML files so browsers fetch the new script.js instead of using the cached old version.

sed -i 's/script.js?v=20261025/script.js?v=20261116f/g' *.html
